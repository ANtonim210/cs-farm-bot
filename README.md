# Telegram File Gate Bot

Телеграм-бот выдаёт один или два файла по уникальной ссылке. Администратор выбирает, будет выдача бесплатной или платной за Telegram Stars.

**Файлы не скачиваются на Render.** Администратор отправляет файл боту, а приложение сохраняет только `source_chat_id` и `message_id` в PostgreSQL. При выдаче бот вызывает Telegram `copyMessage`: Telegram копирует исходное сообщение на своей стороне.

## Что умеет бот

- `/start` — приветствие или открытие файла по персональной ссылке `https://t.me/BOT_USERNAME?start=TOKEN`.
- `/admin` — панель администратора.
- Добавление набора из одного или двух сообщений с файлами: после первого бот спрашивает, нужен ли второй.
- После добавления админ выбирает режим:
  - **Бесплатно** — файл выдаётся без оплаты.
  - **Платно** — бот выставляет счёт в Telegram Stars (`XTR`); цена задаётся админом при добавлении.
- Одна ссылка соответствует одному набору (из одного или двух сообщений).
- **Один пользователь может получить конкретный набор только один раз** — правило одинаковое для бесплатных и платных наборов.
- Повторная оплата по одному набору не принимается: если Telegram всё же пришлёт второй успешный платёж по тому же набору, бот пытается автоматически вернуть лишнюю оплату.
- `/admin` → «Список файлов» показывает ссылки, режим и счётчик выдач. У каждого набора есть кнопка **«Удалить этот файл»**.
- Удаление набора отключает ссылку и удаляет историю его выдач.
- `/myid` — узнать свой числовой Telegram ID.
- `/paysupport` — ответ по вопросам оплаты.
- `/cancel` — отменить текущий шаг добавления файла.
- `/health` — проверка приложения и базы данных для Render/UptimeRobot.

**Проверки подписки на каналы нет.** Функция обязательной подписки и разделы управления каналами удалены.

## Важные моменты

1. Сам файл остаётся в исходном сообщении Telegram. Не удаляй исходное сообщение, иначе копирование может перестать работать.
2. Сообщения с включённой защитой контента Telegram может запретить копировать.
3. Бот не использует `getFile`, не скачивает файл на Render и не хранит его в Neon. В Neon хранятся только метаданные, ссылки и история выдач.
4. Telegram Bot API позволяет повторно отправлять файлы, уже сохранённые на серверах Telegram, по `file_id` без повторной загрузки. Но до продажи очень больших файлов обязательно протестируй копирование конкретного файла в своём боте и аккаунте.
5. Лимит «одна выдача» относится к одной ссылке/набору. Если админ связал два сообщения одной ссылкой, оба сообщения составляют один набор и выдаются вместе.
6. Для цифровых файлов Telegram требует оплату внутри ботов в Telegram Stars (`XTR`). Бот отправляет счёт, проверяет `pre_checkout_query` и выдаёт набор только после `successful_payment`.

## Важно при обновлении существующего бота

При первом запуске новая версия сама добавит нужные поля в таблицу и создаст таблицу истории выдач. Старые файлы и их ссылки сохранятся. Старые записи счётчика тоже сохранятся.

**Историю пользователей за прошлые выдачи восстановить нельзя:** предыдущая версия хранила только общий счётчик, а не ID получателей. Поэтому правило «одна выдача на пользователя» начнёт точно учитываться с момента обновления. Старые файлы станут бесплатными по умолчанию; их можно удалить и добавить заново, чтобы назначить им цену.

## Подготовка

1. Создай бота через `@BotFather` и скопируй токен.
2. Узнай свой Telegram user ID командой `/myid` после запуска или через любого надёжного бота для получения ID. Укажи его в `ADMIN_IDS`.
3. Создай PostgreSQL базу, например в Neon, и скопируй connection string целиком, включая `?sslmode=require`, если эта часть есть.
4. В Neon не нужно создавать таблицы вручную — приложение создаст и обновит их при старте.

## GitHub

Загрузи все файлы проекта в корень GitHub-репозитория. Не загружай токены, пароли, `.env` или строку базы данных.

## Render

Создай **New + → Web Service**, подключи GitHub-репозиторий и укажи:

- Runtime: Python 3
- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- Instance type: Free

Environment Variables:

| Key | Value |
|---|---|
| `BOT_TOKEN` | токен из `@BotFather` |
| `ADMIN_IDS` | числовой Telegram ID администратора; несколько ID через запятую |
| `DATABASE_URL` | PostgreSQL connection string из Neon |
| `WEBHOOK_SECRET` | случайная непредсказуемая строка от 32 символов |
| `WEBHOOK_URL` | необязательно; полный URL Render, например `https://telegram-file-gate.onrender.com`, без `/` в конце. Если не указать, код использует `RENDER_EXTERNAL_URL` Render. |

## UptimeRobot

Создай HTTP(s)-монитор на адрес:

`https://YOUR-SERVICE.onrender.com/health`

Интервал 5 минут, если доступен в тарифе. Успешный ответ:

```json
{"status":"ok","database":"ok"}
```

Проверка помогает уменьшить простой бесплатного Render, но не гарантирует работу 24/7: Render может перезапускать или останавливать бесплатный сервис.

## Как добавить набор

1. Напиши боту `/admin`.
2. Нажми «Добавить файл» и отправь первое сообщение с файлом.
3. Выбери «Добавить второй файл» и отправь второе сообщение либо «Готово, один файл».
4. Выбери «Бесплатная выдача» или «Платная выдача (Stars)».
5. Для платной выдачи введи цену в Stars.
6. Бот пришлёт одну ссылку и ID набора.

## Как удалить набор

1. Открой `/admin` → «Список файлов».
2. Найди нужный набор.
3. Нажми под ним «Удалить этот файл».

Удаление необратимо для записи бота: ссылка станет недействительной, история выдач этого набора удалится. Исходное сообщение с самим файлом в Telegram бот не удаляет.
